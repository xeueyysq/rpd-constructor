# Сервер «Методического конструктора»

Express 5 и PostgreSQL. Запуск, переменные окружения, миграции и проверки описаны в [README в корне репозитория](../README.md), правила разработки — в [docs/CONVENTIONS.md](../docs/CONVENTIONS.md).

## Поиск литературы в ЭБС

`POST /api/find-books` принимает `{bookName, source?}`. По умолчанию поиск запрашивает `megapro`, `lan` и `urait` параллельно. С параметром `source` можно запросить один каталог. В ответе `{books, truncated, unavailableSources?}` каждая книга содержит `source`. При частичном отказе ответ содержит результаты доступных каталогов и список недоступных в `unavailableSources`. При отказе всех каталогов сервер возвращает 502.

Результаты объединяются, дубликаты удаляются в пределах одного каталога, затем книги ранжируются по названию, автору и году. Ответ содержит до 100 книг. `truncated` указывает, что сработал общий лимит или ограничение каталога.

Переменные задаются только в окружении сервера (пустые примеры — в `.env.example`):

- `EBS_LAN_TOKEN` — токен организации для Open API «Лань».
- `EBS_URAIT_PARTNER_ID` — `partner_id` организации для partner API Юрайт.
- `EBS_URAIT_API_KEY` — ключ каталога `token_api` / `api_key`. Старые `pid/token` для SSO не подходят.

ЭБС без реквизитов отмечается как недоступная. МегаПро доступен без этих переменных. Секреты остаются на сервере.

«Лань»: фиксированный `https://openapi.e.lanbook.com/1.0/resource/book`, заголовок `X-Auth-Token`, явные `limit/offset/fields`. API возвращает весь каталог подписки и общее число книг в `count`. [Официальный контракт](https://developers.lanbook.com/open-api/metadata).

Страницы до 1000 записей загружаются последовательно в один снимок с проверкой неизменного `count`, полноты и уникальности ID. Параллельные поиски используют один снимок. Он живёт в памяти 15 минут и ограничен 100 000 книг, 64 МиБ нормализованных данных и 200 страницами. После неудачной загрузки повтор возможен через 30 секунд. Общий срок загрузки составляет 50 секунд, запрос ограничен 10 секундами, ответ страницы — 4 МиБ. Локальный поиск ищет все слова запроса в названии, авторе или годе без учёта регистра и различия ё/е.

Юрайт: фиксированный `https://urait.ru/partner-api/contents`, подпись `md5("partner_id:api_key:time")`, Unix-время в секундах, `query`, `limit=100`, `offset=0`, усечение по `total`. Контракт — [OpenAPI 1.1](https://api.swaggerhub.com/apis/itpm_urait/UraitOpenAPI/1.1). Простое описание строится из названия, авторов, издательства, года и ISBN; готовая библиографическая запись в API отсутствует.

Все запросы ЭБС ограничены четырьмя одновременными обращениями на процесс; перегрузка даёт 429. Редиректы отключены, ошибки/URL/заголовки провайдера не логируются. Внешние тексты очищаются от HTML, ссылки принимаются только с http/https на `lanbook.com` / `urait.ru` и их поддомены, без userinfo и нестандартного порта. Экспорт литературы в HTML РПД дополнительно использует существующий `escapeHtml`.

Реальные подписки и реквизиты проверяются отдельно при подключении. Большие подписки «Лани», превышающие указанные пределы, требуют пересмотра стратегии загрузки; результаты неполного каталога не выдаются.
