# Сервер «Методического конструктора»

Express 5 и PostgreSQL. Запуск, переменные окружения, миграции и проверки описаны в [README в корне репозитория](../README.md), правила разработки — в [docs/CONVENTIONS.md](../docs/CONVENTIONS.md).

## Поиск литературы в ЭБС

`POST /api/find-books` принимает `{bookName, source?}`. Источники: `megapro` (также при отсутствии `source`), `lan`, `urait`. Доступ сохраняется для авторизованных преподавателей, РОП и администраторов. Ответ — прежний `{books, truncated}`; добавление и ручной ввод литературы используют прежнее сохранение РПД.

Переменные задаются только в окружении сервера (пустые примеры — в `.env.example`):

- `EBS_LAN_TOKEN` — токен организации для Open API «Лань».
- `EBS_URAIT_PARTNER_ID` — `partner_id` организации для partner API Юрайт.
- `EBS_URAIT_API_KEY` — ключ каталога `token_api` / `api_key`. Старые `pid/token` для SSO не подходят.

Без реквизитов выбранный источник возвращает понятную ошибку настройки; MegaPro работает как прежде. Секреты не передаются клиенту. Бесшовный вход и регистрация не реализованы.

«Лань»: фиксированный `https://openapi.e.lanbook.com/1.0/resource/book`, заголовок `X-Auth-Token`, явные `limit/offset/fields`. По [официальному контракту](https://developers.lanbook.com/open-api/metadata) это весь каталог подписки, а `count` — общее число книг. Страницы до 1000 записей загружаются последовательно в один снимок с проверкой неизменного count, полноты и уникальности ID. Параллельные поиски разделяют загрузку. Один снимок в памяти живёт 15 минут, предел — 100 000 книг / 64 МиБ нормализованных данных / 200 страниц; просроченный снимок не выдаётся. Неудача не публикует частичный каталог, повторная загрузка возможна через 30 секунд. Общий срок загрузки — 60 секунд, запрос — 10 секунд, ответ страницы — до 4 МиБ. Локальный поиск требует все слова запроса в названии/авторе (без учёта регистра и ё/е); затем применяются прежние дедупликация и ранжирование. Выдаётся до 100 книг с `truncated`. API не даёт версии снимка: изменение данных без изменения count и ID во время обхода обнаружить нельзя.

Юрайт: фиксированный `https://urait.ru/partner-api/contents`, подпись `md5("partner_id:api_key:time")`, Unix-время в секундах, `query`, `limit=100`, `offset=0`, усечение по `total`. Контракт — [OpenAPI 1.1](https://api.swaggerhub.com/apis/itpm_urait/UraitOpenAPI/1.1). Простое описание строится из названия, авторов, издательства, года и ISBN; готовая библиографическая запись в API отсутствует.

Все запросы ЭБС ограничены четырьмя одновременными обращениями на процесс; перегрузка даёт 429. Редиректы отключены, ошибки/URL/заголовки провайдера не логируются. Внешние тексты очищаются от HTML, ссылки принимаются только с http/https на `lanbook.com` / `urait.ru` и их поддомены, без userinfo и нестандартного порта. Экспорт литературы в HTML РПД дополнительно использует существующий `escapeHtml`.

Реальные подписки и реквизиты проверяются отдельно при подключении. Большие подписки «Лани», превышающие указанные пределы, требуют пересмотра стратегии загрузки; результаты неполного каталога не выдаются.
